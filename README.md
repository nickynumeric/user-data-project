# User Data Project

Fetches user data from a public API, cleans it with pandas, and saves it as CSV.

## How to run

- Install: `pip install requests pandas`
- Run: `python fetch_users.py`
- Output: `users_clean.csv`

## What I learned

- Fetching JSON from an API with `requests`
- Flattening nested data with pandas `json_normalize()`
- Saving clean data to CSV and tracking it with Git
